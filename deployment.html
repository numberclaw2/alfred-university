Site Administration

Deployment Notes

This site is static and requires no database, login system, or server-side code.

What to upload

Upload the contents of the Alfred University Website folder to any static web host. The root must contain index.html.

All site navigation, calendar data, resources, PDFs, images, and the Apple Calendar file use relative links and are packaged together.

Mobile use

The site is responsive and includes an installable web-app manifest. Once it is hosted over HTTPS, you can use Safari’s Add to Home Screen option to make Alfred University feel like a dedicated app.

The site itself stores no personal login credentials or cloud database information.

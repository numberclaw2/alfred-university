Site Administration

Deployment Notes

The university website is a static GitHub Pages frontend. The optional Student Progress cloud-sync feature uses a separate Cloudflare Worker and D1 database.

What to upload

Upload the contents of the Alfred University Website folder to any static web host. The root must contain index.html.

All site navigation, calendar data, resources, PDFs, images, and the Apple Calendar file use relative links and are packaged together. The Progress Portal stores data locally first and can optionally synchronize through the separately deployed Alfred Cloud Sync backend.

Mobile use

The site is responsive and includes an installable web-app manifest. Once it is hosted over HTTPS, you can use Safari’s Add to Home Screen option to make Alfred University feel like a dedicated app.

The static site does not contain a master database password or conventional login credentials. When Cloud Sync is enabled, the browser stores the user's Worker URL and private Student Sync Key locally so that progress can synchronize across devices.

Site Administration · v16.1

Deployment Notes

The university website is a static GitHub Pages frontend. The v16.1 Classroom and its completion layer are the instructional source of truth; Student Progress can synchronize through the production Cloudflare Worker and D1 database.

What to upload

Extract the complete flat ZIP and upload every file together to the existing repository root beside index.html. Do not upload a wrapper folder or the ZIP itself. No frontend build or backend migration is required.

All site navigation, the 31-week Classroom curriculum, calendar data, resources, Word/PDF documents, images, and the Apple Calendar file use relative links and are packaged together. The Progress Portal stores data locally first and can synchronize through https://alfred-university-sync.totallywill13.workers.dev.

Mobile use

The site is responsive and includes an installable web-app manifest. Once it is hosted over HTTPS, you can use Safari’s Add to Home Screen option to make Alfred University feel like a dedicated app.

The static site does not contain a master database password or conventional login credentials. When Cloud Sync is enabled, the browser stores the user's Worker URL and private Student Sync Key locally so that progress can synchronize across devices.

Export Progress and keep the Recovery Key separately before updating. Keep the existing site address; a new domain is a new browser origin and also needs a Cloud Sync allowed origin. Do not clear browser site data as a normal refresh step.

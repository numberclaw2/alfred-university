## Visual delivery policy

The OpenStax Subject 1 images are remote-linked from the credited UCF Pressbooks source rather than copied into this repository. Each in-lesson figure includes alt text, caption, source link, and license link. If a remote image is temporarily unavailable, the explanatory lesson text and figure caption remain, and the source page can be opened directly.

The NIST material is used as a factual reference for SI prefix values and notation. No NIST image is redistributed in this update.

# AU-ESET 301 v16.3.40 — External Source / Benchmark Ledger

This ledger records the external curricula, standards, manufacturer resources, occupational sources, and other authoritative references used by the v16.3.40 Career reconstruction and acceptance repair. Alfred remains an independent self-study environment; these references do **not** imply endorsement, accreditation, certification approval, partnership, or formal equivalence.

## Provenance relationship policy

- **Directly based on** — the Alfred competency closely follows a clearly defined external competency/outcome.
- **Adapted from** — Alfred preserves the substance but changes wording, scope, sequencing, or application context.
- **Informed by** — the source influenced skill definition, instructional depth, or prerequisite order.
- **Cross-checked against** — Alfred-authored content was verified against an external reference.
- **Alfred-authored integration standard** — Alfred combines several externally grounded ideas into one integrated competency; it is not an official standard of the cited organizations.

The v16.3.40 repair did not add decorative citations. Every source ID below is referenced by at least one current Career standard or curriculum block.

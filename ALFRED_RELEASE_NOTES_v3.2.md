- A static GitHub Pages website can potentially serve a committed PDF to site visitors **even when the source repository is private**. This release does not assert or verify repository visibility. Only upload the bundled PDF to a location where you have suitable distribution rights and access controls. For personal-only use without public hosting, keep using Alfred's device-local private PDF connection instead.

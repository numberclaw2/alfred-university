Capstone Brief

Embedded Hardware + Automated Test System

Your system must combine a microcontroller, a real peripheral, an interactive input/output path, UART communication, modular firmware, a Python host/test tool, instrumentation evidence, fault handling, and documentation that another technical person can reproduce.

Engineering Review Sequence

Capstone milestones

Each milestone produces something you can later show or discuss in an interview.

22

Design Review

Requirements, architecture, block diagram, BOM, pin map, interface plan, and test plan.

24

Hardware Bring-Up

Current-limited power-up, rails, GPIO, UART, SWD, baseline current, and staged verification.

25

Sensor / Interface Integration

I2C or SPI peripheral, raw data, engineering units, datasheet verification, and logic-analyzer evidence.

26

Firmware Architecture

Modular C, nonblocking state machine, timers/interrupts, timeouts, error states, and diagnostics.

27

Python Test Automation

Serial control, parsing, logging, PASS/FAIL checks, malformed-response handling, and plotting.

28

Fault Injection + Test Report

Reproduce → measure → isolate → root cause → fix → verify, with defensible evidence.

29

R&D Role-Proof Dossier

Solder/rework, harness/prototype workmanship, instrumentation, troubleshooting story, and employer-facing documentation.

Required Evidence

What should exist when Project 1 is finished.

01

Requirements + Block Diagram

What the system must do and how the pieces connect.

02

Repository + README

Firmware, host code, build notes, wiring, and usage.

03

Bring-Up Log

Power, rails, current draw, GPIO/UART/SWD checks, and failures.

04

Protocol Captures

Logic-analyzer proof for UART and the selected I²C/SPI interface.

05

Automated Test Results

Python-controlled test cases, PASS/FAIL, logs, and plots.

06

Root-Cause Report

A real failure investigated with measurements and verified correction.

07

Instrument Evidence

DMM, scope, supply, analyzer, and debugger used intentionally.

08

Portfolio Demonstration

A concise employer-facing explanation of design, failures, and results.

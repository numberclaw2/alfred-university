- **Independent mock exam validation:** M29 and M30 continue to provide two functional *rehearsals* using historical questions from the rest of the site, with overlapping IDs. Neither is a newly authored, unseen or independently reviewed 100-question form; both must remain ineligible for certification-readiness status. Page-specific written sources already exist on 126 pages. Images/videos hosted externally may fail offline or if blocked by the source platform; learning explanations and links remain available.

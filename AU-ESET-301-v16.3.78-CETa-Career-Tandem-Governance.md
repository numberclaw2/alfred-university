# AU-ESET 301 — v16.3.78 CETa ↔ Career Tandem Governance

## Governing rule
CETa certification knowledge and Career occupational performance are **co-equal but non-substitutable** evidence streams. A week may be labeled `VERIFIED_PASS` only when **CETa + Career + Tandem** gates all pass.

## Canonical standards universe
- CETa: **262**
- Career: **95**
- Total: **357**
- Previously routed Career rows retained for re-audit: **81**
- Newly canonical Career rows with pending/performance routes: **14** (`C3.7`, `C3.8`, `C14.1–C14.6`, `C15.1–C15.6`)

Presence in the canonical matrix never means a route is accepted. Every row carries route state.

## Five relationship types
1. `CETA_TO_CAREER` — theory/model first; technician application follows.
2. `CAREER_TO_CETA_FORMALIZATION` — a bounded technician behavior is introduced first; later CETa instruction formalizes broader theory/terminology.
3. `CONCURRENT_SHARED` — theory and occupational use belong together.
4. `CAREER_EXTENSION` — job skill goes beyond CETa while using CETa foundations where relevant.
5. `CETA_ONLY_BREADTH` — certification breadth is taught/mastered without inventing a Career artifact solely to create symmetry.

## Machine-readable dependency rule
Every Career standard has:
- prerequisite CETa codes already taught before first Career use;
- concurrent CETa codes first activated in the same week;
- later CETa reinforcement/formalization codes that **must not be treated as prerequisites**.

This distinction prevents future-theory leakage.

## Three-gate weekly acceptance
### CETa gate
Assigned CETa rows must exist in canonical coverage and retain valid teaching/mastery/retention routes.

### Career gate
The v16.3.77 occupational acceptance system must pass, including physical/performance evidence when applicable.

### Tandem gate
The relationship type and prerequisite codes must be explicit; no future-theory leakage or false equivalence is allowed; visible handoffs must be added during week remediation; and neither track's evidence can substitute for the other.

A failed Tandem gate blocks `VERIFIED_PASS`.

## Current baseline
- Week 2: `VERIFIED_PASS` across the combined model.
- Weeks 1 and 3–31: `REMEDIATION_REQUIRED` until they separately earn Career and Tandem acceptance.

## Important scope rule
This release changes governance, coverage state, dependency data, labels, and acceptance logic. It does **not** rewrite CETa or Career lesson content.

## CETa-only breadth preservation
Certification breadth is never deleted merely because it lacks a direct Career artifact. The current explicit breadth list is published in `AU-ESET-301-v16.3.78-CETa-Only-Breadth-Policy.csv`. These rows remain fully teachable/testable for CETa while Career time stays focused on occupationally relevant performance.
